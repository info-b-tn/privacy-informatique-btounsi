# informatique بالتونسي — Politique de confidentialité

Ce dépôt contient la page de politique de confidentialité pour l'application mobile **"informatique بالتونسي"**.

## But
Fournir une URL publique à utiliser dans la Google Play Console / Google Console.

## Fichiers importants
- `privacy_policy.html` : page HTML publique de la politique de confidentialité.
- `LICENSE` : licence du dépôt.

## Déploiement (GitHub Pages)
1. Pousser le repo sur GitHub.
2. Activer GitHub Pages (branch `main` / dossier `/ (root)`), ou créer une branche `gh-pages`.
3. La page sera disponible à :
   `https://github.com/info-b-tn/privacy-informatique-btounsi/privacy_policy.html`
